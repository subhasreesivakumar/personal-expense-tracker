
# Personal Expense Tracker

**Created by:** Subhasree S.  
**Course:** BSc Computer Science with AI and Data Science

## About the Project
A beginner-friendly Python application that helps users record expenses and calculate their total spending.

## Features
- Add expenses
- View recorded expenses
- Calculate total spending
- Validate expense amounts

## Technology Used
- Python 3

## How to Run
1. Download `expense_tracker.py`.
2. Open a terminal in the file's folder.
3. Run: `python expense_tracker.py`

## Learning Outcomes
Practised loops, conditional statements, lists, dictionaries, functions of built-in Python operations, and input validation.
